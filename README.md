# NL-TScript

JavaScript temelleri ve Playwright'a hazırlık için pratik dosyaları.

## İçerik

- `basics/` — değişken tipleri, boolean, artırma/azaltma, string birleştirme, ASCII değerleri, matematik operatörleri gibi konularda küçük JS alıştırmaları.

## Kurulum

```bash
npm install
```
